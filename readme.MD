# Project Documentation: Nissan Elite
initial code come from Nissan AC

This project uses a framework called Yue framework by Justin Yue, who onced worked for destination.  It closely emulates Laravel, so some Laravel experience can be applied to using this framework.

The routes are stored in /public/index.php

Twig templating is used.

Database ORM uses the Meedoo framework.

The templates are stored under /app/views.

To get npm run dev to work. You may need
npm install is-obj
npm install cross-env

Settings are store in 
/app/helpers/.env  
/app/helpers/setting.php
